# Pacing Guide (18 weeks)

Assumes ~5 class periods/week of ~50 minutes (adjust as needed). Each unit is roughly one week. Buffer days are built into Modules for catch-up, re-teaching, and lab troubleshooting.

## Suggested rhythm within a week
- **Day 1:** Hook + direct instruction on the new concept; vocabulary.
- **Day 2:** Guided practice / demo; begin lab.
- **Day 3:** Lab work (independent/pairs); circulate and support.
- **Day 4:** Finish lab; share-outs; lab journal writeup.
- **Day 5:** Assessment (quiz/check) + ethics discussion + preview next unit.

## Flexible scheduling notes
- **Block schedule (90 min):** combine Days 1–2 and Days 3–4.
- **Shorter terms:** Modules 0–3 form a coherent "intro" if you must cut. Modules 4–5 are the natural trim points.
- **Club / enrichment:** Units 1, 2, 4, 7, 8, 10, 18 make a strong "greatest hits" sequence.
- **Built-in buffer:** plan one flex/catch-up day per module for lab issues and re-teaching.

## Major graded milestones
- **End of Module 2 (Week 9):** Reconnaissance mini-project (recon report on a lab target).
- **End of Module 3 (Week 14):** Web-vulnerability writeup project.
- **End of Module 5 (Week 18):** Capstone — CTF performance + professional report + presentation.
